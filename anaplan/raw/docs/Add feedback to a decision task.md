Approvers can add comments and feedback when they approve, reject, or send back a task. The comment is saved directly back to the model, linked to that specific line item. This feature is compatible with batch approvals.

To enable comments on a decision task:

1. Create or edit a [decision task](https://help.anaplan.com/11cd0601-0221-4705-b101-30f00490846a).
2. In the **Approver** section, select **Assign to users from a line item in a module** > **Select**.
3. Select a module.
4. Under **Approver settings**, select an option in the **Line item for feedback notes** dropdown. This line item must be formatted as text in your model.

**Note:** Populating too many text cells can add density to your model and cause it to slow down.

Once you publish your workflow template, the next time your workflow runs, a text pop-up will appear when an approver approves, rejects, or sends back a task. The approver can enter a comment of up to 500 characters, which will be added to your selected module. Adding a new comment will overwrite an existing one. Feedback can't be added when a task is approved or rejected via email.
