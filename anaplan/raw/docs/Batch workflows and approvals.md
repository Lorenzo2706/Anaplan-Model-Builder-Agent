[Workflow Advanced](https://help.anaplan.com/workflow-advanced-f6ad25f7-2e58-4e06-8132-d1cc42dff1b0 "Workflow Advanced ")

Workflow Advanced enables batch workflows and approvals. Workflow owners can run the same workflow for multiple list items in one go without having to create multiple workflows. Approvers can manage multiple decision task notifications at once.

**Note:** Workflow Advanced is an entitled service and requires a separate subscription to enable the feature. Your Account Executive can assist you with this. The features are tenant-specific, so in a multi-tenant environment, the Workflow Advanced features only display on tenants that have the feature enabled.

To enable batch workflows:

1. In the **Workflow builder screen**, select to open the **Template settings** panel.
2. Under **Batch run**, switch on the **Enable batch run for this template** toggle.
3. Use the **Select** button in the **Select line item from a module** field to configure batch run data.
4. Select a **Workspace**, **Model**, and **Module**.
5. Under **User settings**, select a **Users line item** to set where the workflow can find the users who can run this workflow, and a **User line item filter** to dictate which of those users will be included.
6. Under **Context setting**, select **Iterate over all**.
7. Select **Publish** to save your settings to the template.
8. [Configure your workflow template](https://help.anaplan.com/11cd0601-0221-4705-b101-30f00490846a) as needed.

To configure the batch workflow on a page:

1. Select **Configure action** on a new card, or hover over your card and select **Edit** .
2. In the **Actions** tab, expand **Workflow templates** and enable the workflow template created for batch run.
3. [Configure your action card](https://help.anaplan.com/bf2461bf-f816-4736-903a-4ce8bce33e70) as needed.

To enable batch approvals:

1. Create a [decision task](https://help.anaplan.com/11cd0601-0221-4705-b101-30f00490846a).
2. Under **Approvers**, select **Enable batch approval** to enable the approver to approve or reject more than one task at a time.  
	When workflows are started, each approver will receive a single email containing all their pending approvals. This email is sent out at 00:00 UTC.

To approve/reject multiple tasks:

1. Select **View approvals** in the batch approval email.
2. Select any task in the **Batch approval** pane to view the relevant page and context.
3. Check the box next to the tasks you want to approve.
4. Select **Reject** or **Approve**.

**Note:** [**Send back**](https://help.anaplan.com/9ec4f9ba-5194-4a9b-b31e-d283735206bc) is only enabled for tasks that have had the **Enable send back for approver** toggle switched on during workflow creation.

To go to the **Task approval** tab in the task inbox, select **View tasks** at the bottom of the pane.
