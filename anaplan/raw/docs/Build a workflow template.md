As a workflow owner, you can use the Workflow builder to build and edit workflow templates. Workflow templates can be built and customized according to your needs to run business processes.

The template builder enables you to visualize your workflows, giving you a clear view of each task or step as you build them.

![](https://assets-us-01.kc-usercontent.com/cddce937-cf5a-003a-bfad-78b8fc29ea3f/f5ea4f71-a28e-4936-b7d9-1d788344e6b0/workflowtemplatebuilder.png)

To create a template:

1. Select **Create** > **Template**.
2. Enter a **Name** and **Description** for your template. You can edit these in the workflow builder by selecting .
3. In the workflow builder, you can add a step to your workflow by selecting it in the right panel, or by dragging and dropping it into the canvas. You can select one of these tasks:
	- [**Page tasks**](https://help.anaplan.com/afc734da-cb16-44f6-a0d3-206d2816876d):One-off tasks assigned to a single Anaplan user.
		- [**Group tasks**](https://help.anaplan.com/751b22cd-6c85-46bc-a071-e0aee9608898): Tasks that are assigned to a group of users. Any of the users can complete the task.
		- [**Hierarchical tasks**](https://help.anaplan.com/eb2eaca9-1515-4d0d-a058-92f2787b3e1d): Groups of tasks that follow a sequence of dependent tasks.
		- [**Machine tasks**](https://help.anaplan.com/f7efde27-771e-4d5a-bb8c-3c1316e35b48): tasks driven by Anaplan actions. Machine tasks don't require user interaction.
		- [**Decision tasks**](https://help.anaplan.com/11cd0601-0221-4705-b101-30f00490846a): Task that decides on approvals of specific steps.
		- [**Notification step**](https://help.anaplan.com/27477d8b-ae1e-4dd9-b660-cf1fbf2b5402): Tasks that send a custom notification message to an assigned user.
		- [**Anaplan Data Orchestrator**](https://help.anaplan.com/87e61349-3e89-47c2-a5ab-9d9820e2003f): Tasks driven by Anaplan Data Orchestrator actions.  
		You can select to select what happens when a Data Orchestrator step fails in the workflow.
4. Once you've added your first task, you can add more by selecting one of the on the canvas. The position of the icon indicates where in the workflow your new task will be added.  
	You can reorder your the tasks in your template by dragging and dropping them to a new position on the canvas.
5. To remove a step, select a step and select in the **Configure step** panel.
6. Either select:
	- **Publish** to publish your template.
		- **Save as draft** if more changes are needed. You can return to this template later.

Once you've published a workflow template, you can run it by selecting it in **Templates** > **Start workflow**. You can also [create a schedule](https://help.anaplan.com/a324b583-c8dd-404e-8967-16e43988054f) for it to run regularly or at a specific time.

As a workflow owner, if you want to receive general email notifications about the workflow, you can select and switch on the **Send notifications to Workflow Owner** toggle. Switch this option off you only want notifications when action is required, for example, when something is broken, blocked, or canceled in the workflow.

**Note:** The **Send notifications to Workflow Owner** toggle is switched off by default.
