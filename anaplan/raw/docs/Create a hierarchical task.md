Hierarchy tasks enable the progression of a task through a given hierarchy in a way that removes bottlenecks by flowing tasks through different branches of the hierarchy at different speeds, depending on how work is completed.

**Note:** This type of task must be part of a template or its running workflow. It cannot be created as an individual task.

Hierarchy tasks can be created based on [composite hierarchies](https://help.anaplan.com/cabf4596-28b5-4849-a028-d2e610905b7d) built into your model.

To create a hierarchical task:

1. In the **Workflow builder** screen, select the **Hierarchical task** option or drag and drop it into the workflow.
2. In the configuration panel, enter a **Task title** and **Instructions** for the task assignee.
3. Select the page that you want to use to drive this task. The same page is used for all levels within the hierarchy.
4. In the **Assignment** section, select the hierarchy you want to use to manage the flow of your task.
5. You can turn on:
	- **Hide reject option for approver**
		- **Skip on blank assignees:** If the module line item contains no assignees, this step is skipped and the workflow continues.
6. Select whether you want the **Task flow direction** to be **top-down** or **bottom-up.**
7. For each level, you can:
	- **Omit hierarchy**
		- **Configure level**
		- Select a module. Only modules dimensioned by selected line items in the hierarchy will appear.
				- **Assignee settings**: Select an assignee line item from the dropdown. Select a line item to update once the task has been completed.
				- **Approver settings**: Select an approver line item from the dropdown. Select a line item to update once the task has been approved or rejected.
				- **Context setting**: you can select a value from the dropdrown, or select to access the **Sync to workflow** option.
				- **Enable completion check**: Enable this to select a Boolean line item that verifies this task can be completed. You can also select a text line item to tell users why their task couldn't be completed
		- **Configure page**
8. In the **Due** section, select a due date from the dropdown. You can select a date up to 31 business days into the future.
9. Either select:
	- **Publish** to add this task to the template.
		- **Save as draft** if more changes are needed to the template.
