A Workflow owner can create and add machine tasks to Workflow templates. Machine tasks correspond to actions in worksheets or boards, or Anaplan Optimizer actions, and are carried out automatically by Anaplan.

You must **Create a template**, or **Edit template**,in the **Workflows** section of the **Workflow** screen.

To select an action in the Workflow Builder, a model builder must first create the action in a model.

**Note:** This type of task must be part of a template or its running workflow. It cannot be created as an individual task.

To create a machine task:

1. In the **Workflow builder screen**, select the **Add a machine task** option.
2. In the right-hand configuration panel, enter a **Task title** and **Instructions**. The instructions are descriptive of the action that is automatically carried out by the system.
3. In the **Select Action** section, select in order:
	- An **Action type**: These are standard model actions, such as [import, export](https://help.anaplan.com/b945e7f1-71c8-42ce-82ec-0987edd28bea), and [data write](https://help.anaplan.com/a2f9fe03-2da9-4969-9ae5-e6e2bd41d850).
		- A **Workspace**: The [workspace](https://help.anaplan.com/625ac3bf-3858-4b68-ada8-704b5ecf88e4) that contains the model and its actions.
		- A **Model**: The model where the actions exist.
		- A **Process**:The name of the business process in the model.
4. Either select:
	- **Publish** to add this task to the template.
		- **Save as draft** if more changes are needed. You can return to this task later.
