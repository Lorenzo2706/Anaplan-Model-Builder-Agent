[Workflow Advanced](https://help.anaplan.com/workflow-advanced-f6ad25f7-2e58-4e06-8132-d1cc42dff1b0 "Workflow Advanced ")

Parallel can be used to send approval tasks to multiple users at the same time, where each stakeholder requires a distinctive experience, for example reviewing a different page, or requiring different instructions/guidance information.

**Note:** Workflow Advanced is an entitled service and requires a separate subscription to enable the feature. Your Account Executive can assist you with this. The features are tenant-specific, so in a multi-tenant environment, the Workflow Advanced features only display on tenants that have the feature enabled.

![](https://assets-us-01.kc-usercontent.com/cddce937-cf5a-003a-bfad-78b8fc29ea3f/9e146657-e0d0-41fb-be66-1d3e1cf48d22/AW_parallelsteps.png)

To create a workflow with parallel steps:

1. Add a task to a new or existing [workflow template](https://help.anaplan.com/46e9d0c5-c59c-4a70-853e-5586c0f616cc). In this example, we'll use a [decision task](https://help.anaplan.com/11cd0601-0221-4705-b101-30f00490846a) to create a workflow where we want approval from several different departments at the same time. Enter a **Task title** and **Instructions** for the task assignee.

**Note:** Adding a decision task automatically creates [branching](https://help.anaplan.com/45b1cd25-c944-46c0-8b4f-aa5e428e7f67). Branching isn't compatible with parallel steps.

2. From the **Select page** section, you can use the search function to find a page and select it.
3. In the **Approver** section, select one or more approvers for your decision task.
4. Switch off the **Enable branching** toggle.
5. You can now see on either side of your decision task. Select it to add a new task in parallel with the one you created.  
	This block that includes one or more parallel steps in your workflow is highlighted in pink.
6. Add another decision task from the right panel. You can configure it in the same way.  
	You can add up to 20 parallel tasks in one block.
7. You can add as many blocks of parallel steps as you need in a workflow. For example, once your approvals are complete, you may want to distribute the approved data into two different models or modules at once. You can do this by creating parallel [machine tasks](https://help.anaplan.com/f7efde27-771e-4d5a-bb8c-3c1316e35b48).
8. Select the below the parallel block to add a new step.
9. Select a **Machine** task from the right panel and enter a **Task title** and **Instructions**.
10. In the **Select action** section, select in order:
	- An **Action type**: These are standard model actions, such as [import, export](https://help.anaplan.com/b945e7f1-71c8-42ce-82ec-0987edd28bea), and [data write](https://help.anaplan.com/a2f9fe03-2da9-4969-9ae5-e6e2bd41d850).
		- A **Workspace**: The [workspace](https://help.anaplan.com/625ac3bf-3858-4b68-ada8-704b5ecf88e4) that contains the model and its actions.
		- A **Model**: The model where the actions exist.
		- A **Process**: The name of the business process in the model.
11. Add another **Machine** task from the right panel. You can configure it in the same way.
12. You can add a due date in the **Due** section on the right panel.
13. Once you are happy with your template and are ready to start using it, select **Publish.**
