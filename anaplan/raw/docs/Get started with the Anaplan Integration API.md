Understand how the Integration API works, its behaviors, and what you should consider when building integrations.

The Anaplan Integration API enables external applications, scripts, and integration tools to connect securely with Anaplan models. It supports automated data movement, model interaction, and process execution, helping you replace manual import and export steps with repeatable, system-driven workflows. With support for both bulk data operations and smaller transactional requests, the API can be used to upload and import data, export model outputs, run actions and processes, retrieve model metadata, and support operational tasks such as monitoring task status.
