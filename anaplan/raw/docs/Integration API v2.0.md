[Anaplan API](https://help.anaplan.com/anaplan-api-844c6d40-a21c-423d-8435-ebaaa0372b76 "Anaplan API")

The Anaplan Integration API v2.0 provides a set of secure REST endpoints to move data into and out of Anaplan models, run model actions, and read or update selected model metadata and transactional data.

Use these when you want to:

- Discover the workspaces, models, modules, views, lists, files, imports, exports, processes, and actions available to an integration user.
- Upload source files and run imports.
- Run exports and download generated files.
- Run processes or delete actions and monitor task status.
- Read view data, list data, and selected model metadata.
- Write cell data or list items directly through transactional endpoints.

You can also find a complete collection of these Anaplan endpoints on [Postman](https://www.postman.com/apiplan/official-anaplan-collection/collection/2m6331d/official-anaplan-collection).
