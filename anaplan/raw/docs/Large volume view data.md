English

Large volume view data endpoints are used to read larger datasets from Anaplan views when a limited-volume cell data request is not suitable.

These endpoints provide asynchronous, paged access to large view datasets. They help extract a large amount of data from a saved view without relying on a standard export action or a small direct data request.
