English

Model user information endpoints are used to identify the authenticated user and retrieve information about users who have access to a workspace or model.

These endpoints provide user discovery and identity context. They help determine which user is authenticated, which users are available in this workspace or model, and what user information is needed for access validation, administration, or provisioning.
