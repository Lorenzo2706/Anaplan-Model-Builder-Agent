As a workflow owner, you can use the **Usage**, **Running**, and **Completed** pages to keep track of the workflows in their organization. You can monitor workflow progress or identify any issues within workflows.

In **Usage,** you can see an overview of workflow usage. Set a date in **From** and **To** to specify a period for which you want to view workflow usage numbers.

You can see the total number of users who have started a workflow, created a template, and launched a workflow from a page. You can also see how many tasks have been issued and completed, and the number of workflows that are in progress, canceled, failed, completed, rejected, and require action.

Select the **Total users** number to open a panel which lists the names of the users and their email address.

When a template is started, it creates a running workflow. The same template can be run many times at once, and each one can be tracked and monitored in the **Running** tab.

You can select a workflow to view its details. Select **View** to view the workflow template. In **Steps**, you can see which step the workflow is currently on, and the steps that are complete.

Select **Cancel workflow** to stop the running workflow.

Enter a workflow name in the search bar to search for a specific running workflow.

Select to open the **Filter** panel to filter the workflow list by workflow status, the user it was started by, and start date.

To filter running workflows by status, select a **Status:**

- In progress
- Action required

All the workflows with that status will display.

To filter running workflows by user, select a user from the **Started by** list, or use the search bar to search for a specific user. All the workflows created by your selected user will display.

To filter running workflows by date, select an option from the **Start date** dropdown:

- Today
- Yesterday
- Less than one week ago
- Less than two weeks ago
- Less than three weeks ago
- Less than one month ago

All the workflows started in your selected time period will display.

You can find stopped workflows in **Completed workflows**. This includes workflows that have been canceled, failed, or rejected. You can select a workflow to view its details. Select **View** to view the workflow template. In **Steps**, you can see all the steps in the workflow.

Select **Delete** to delete this instance of the workflow.

Select **Export** to export a log of the workflow in a CSV file. This log details the tasks and events that occurred in the workflow, as well as timestamps for each of them. It also contains `GUIDs` for users involved in the workflow, such as assigners, assignees, and recipients, where relevant.

[See an example of a workflow log](https://assets-us-01.kc-usercontent.com/cddce937-cf5a-003a-bfad-78b8fc29ea3f/b2bf7c0f-d4f2-45b8-9c6e-f8e3e1549110/workflow-history-example.csv).

Enter a workflow name in the search bar to search for a specific completed workflow.

Select to open the **Filter** panel to filter the workflow list by workflow status, the user it was started by, and start date.

To filter completed workflows by status, select a **Status:**

- Completed
- Canceled
- Failed
- Rejected

All the workflows with that status will display.

To filter completed workflows by user, select a user from the **Started by** list or use the search bar to search for a specific user. All the workflows created by your selected user will display.

To filter completed workflows by date, select an option from the **Start date** dropdown:

- Today
- Yesterday
- Less than one week ago
- Less than two weeks ago
- Less than three weeks ago
- Less than one month ago

All the workflows started in your selected time period will display.
