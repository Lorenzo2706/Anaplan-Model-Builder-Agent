You can complete, approve, or reject tasks that are assigned to you in the User Experience.

If a Workflow owner assigns you a task, you are notified by email and Anaplan notifications. If you have the [Anaplan mobile app on your mobile device](https://help.anaplan.com/e2debd79-6614-487a-a33e-43f9feea7e7e), you also receive a push notification. Use these notifications to action a task. Otherwise, access the task inbox and select the task you want to action.

The task details pane provides instructions on how to complete the task. Read the instructions and then select **View task** to open the page that contains the task.

If [enabled by a workflow owner](https://help.anaplan.com/de38fd18-e16d-421a-817b-256b8d9f7340), you can action tasks via email notifications. Select the **Approve**, **Reject**, or **View** button in the notification email. The task is performed automatically, and you are navigated to the relevant page in Anaplan.

**Note:** If you aren't logged in to Anaplan, you'll have to complete the standard authentication process as part of conducting an approval. Once authenticated, subsequent actions will flow more smoothly.
