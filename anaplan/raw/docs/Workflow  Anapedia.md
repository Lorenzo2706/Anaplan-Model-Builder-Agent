Use Workflow to design, implement, and manage automated business processes within the Anaplan user experience. Workflow enables you to create one-off tasks or more complex workflows, and assign them to stakeholders.

With Workflow, you can create repeatable business processes in the Anaplan user experience. This speeds up task assignment and the approval process. Workflow tells users which tasks they're responsible for, when they are due, and how to complete them.

Workflow provides:

- An intuitive workflow design process.
- Full integration with the Anaplan user experience and modeling experience.
- Creation of workflow actions and their inclusion in pages.
- Workflow progress, monitoring, and tracking of user tasks.
- Task-level approval processes.
- User notifications on web, email, and mobile.
- Task management features such as reassignment and delegation.
- Reusability of workflows through the use of templates.
- Mobile functionality in the Anaplan mobile app, to action workflow tasks on the go.
- [Event auditability](https://help.anaplan.com/a6832db5-d137-4f47-89c2-d7645b0dfd61) for Tenant Auditors in Anaplan.
- Tasks to run a scheduled process with [Anaplan Data Orchestrator](https://help.anaplan.com/87e61349-3e89-47c2-a5ab-9d9820e2003f) actions.
- Integration with [Anaplan Optimizer](https://help.anaplan.com/e8eac6ea-bfac-43a1-abbb-3dad60cea523) through machine tasks.

[Workflow Owners](https://help.anaplan.com/e41fa3aa-caf6-4484-a8b2-46675f0d3937), an administration role in Anaplan, can create tasks and [workflow templates](https://help.anaplan.com/46e9d0c5-c59c-4a70-853e-5586c0f616cc), and launch them as running workflows.

**Note:** Workflow is an entitled service that must be bought separately to enable the feature. Your Account Executive can assist you with this. To fully use the functionality of Workflow you need the [Workflow Owner](https://help.anaplan.com/e41fa3aa-caf6-4484-a8b2-46675f0d3937) role. Both the role and feature are tenant-specific, so in a multi-tenant environment, the Workflow feature only displays on tenants that have the feature enabled.
