# Triage labels

| Canonical role | Local Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | More information needed |
| ready-for-agent | ready-for-agent | Specified for agent implementation, subject to blockers |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use these exact strings when a skill requests a triage role. Execution states `claimed` and `resolved` are separate from these triage roles.
